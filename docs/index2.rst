Welcome to Flask-RealTimeAnalytics's Documentation!
==================================================

Flask-RealTimeAnalytics is a Flask extension for real-time analytics dashboards. It tracks user behavior, API usage, and performance metrics, providing live updates via WebSocket integration. The extension is database-agnostic, leveraging SQLAlchemy for compatibility with databases like PostgreSQL, MySQL, and SQLite.

Key Features
------------

- Real-time tracking of HTTP requests, response times, and user data.
- WebSocket-powered dashboard for live analytics visualization.
- Seamless integration with SQLAlchemy-supported databases.
- Easy setup for both inline and application factory Flask patterns.
