Contributing
============

We welcome contributions to Flask-RealTimeAnalytics! To contribute:

1. Fork the repository on `GitHub <https://github.com/yourusername/flask-realtime-analytics>`_.
2. Create a branch (e.g., ``git checkout -b feature/new-feature``).
3. Make changes, ensuring code style consistency (use ``black`` or ``flake8``).
4. Write tests in ``tests/`` using ``pytest``.
5. Commit changes with clear messages (e.g., "Add support for X feature").
6. Submit a pull request with a detailed description.
7. Report bugs or feature requests via `GitHub Issues <https://github.com/TonyRolfe/flask-realtime-analytics/issues>`_.
